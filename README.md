# ATHENAI LEAD RECOVERY & SALES CRM CORE

Диагностическое тестовое задание для AthenAI: локально запускаемый вертикальный
срез системы обработки входящих лидов вымышленной B2B-компании
**AthenAI DemoService**.

> Статус: этап 1 из 14 — каркас проекта. Полная документация (архитектура,
> поток данных, модель угроз, инструкция по запуску) появится ближе к финалу.

## Быстрый старт (одна команда)

```bash
docker compose up --build
```

После запуска:

| Что | Где |
|---|---|
| REST API и Swagger-документация | http://localhost:8080/docs |
| Mock-CRM (игрушечная «внешняя» CRM) | http://localhost:8081/healthz |

Система не требует ни одного внешнего ключа: по умолчанию квалификация лидов
выполняется детерминированным mock-провайдером. Переключение на DeepSeek —
через `QUALIFIER_PROVIDER=deepseek` в `.env` (см. `.env.example`).
